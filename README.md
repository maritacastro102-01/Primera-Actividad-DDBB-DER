Actividad Inicial: Introducción a las Bases de Datos

Paso 1: Elegí un contexto
Imaginá que vas a organizar la información de una biblioteca de barrio.
Si preferís, podés elegir otro contexto (por ejemplo: una tienda, una veterinaria, un gimnasio, una escuela, etc.).
Paso 2: Identificá las entidades
Hacé una lista de al menos 3 entidades o tablas que serían necesarias en tu sistema.
Por ejemplo, en una biblioteca podrían ser:
Libros
Usuarios
Préstamos
Autores
Para cada entidad, indicá qué tipo de información (atributos) guardarías. Ejemplo: Usuario: nombre, DNI, teléfono, correo electrónico.
Paso 3: Definí las claves
Para cada tabla:
Indicá cuál es su clave primaria (PK).
Agregá las claves foráneas (FK) que consideres necesarias para relacionar las tablas.
Ejemplo: En la tabla Préstamos, podría haber una FK que se relacione con el Usuario y otra con el Libro.
Paso 4: Establecé las relaciones
Describí las relaciones entre las entidades usando frases simples.
Por ejemplo:
“Un usuario puede tener varios préstamos.”
“Cada préstamo pertenece a un solo usuario.”
“Un libro puede estar asociado a un solo autor o a varios autores.”
Paso 5: Modelá tu mini base de datos
Con toda la información anterior, creá un mini modelo de datos. Podés hacerlo, Dibujando las tablas y sus relaciones en papel o usando una herramienta digital (por ejemplo: Draw.io o MySQL Workbench).
Parte 6: Reflexión Final
Responde brevemente:
1.¿Qué fue lo más fácil y lo más difícil al diseñar tu base de datos?
2.¿Por qué creés que es importante modelar antes de crear la base de datos en un sistema real?
